# Privacy

Daily AI Wallpaper is designed around local, user-authorized data.

- The public website does not read Codex conversations.
- A portrait selected in the website remains in the current browser session and is not uploaded by this project.
- The Codex Plugin may read only the tasks the user authorizes for the requested period.
- Conversation transcripts, portraits, credentials, and generated personal reports must never be committed to this repository.
- The AI capability score must be based on real task evidence. Missing evidence is shown as `待评估` instead of a guessed score.
- The macOS helper accepts wallpaper images only from the loopback interface on the same computer.

The deployed site contains static demo artwork. It does not include the project author's raw conversations or portrait.
